# Security policy

## Reporting a vulnerability

Email [bahieldin.mark@gmail.com](mailto:bahieldin.mark@gmail.com) with the
affected repository and version, impact, reproduction steps, and a safe way to
contact you.

Do not report vulnerabilities through public GitHub issues, discussions, or
pull requests. Do not include live credentials or customer data in a report.
MarkAIOrg will coordinate a private response.
